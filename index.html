01

READ THE SHAPE

Start with the silhouette.

A cylindrical boiler, a cab, a tender, and a rhythm of wheels. Those few decisions make a locomotive recognizable before the rivets arrive.

Tom Krcha’s thread begins with an old engineering drawing and an editable Blender model. We used that approach as inspiration for two original interpretations: an exposed heritage engine and a streamlined Hudson.

02

ENCODE THE PROPORTIONS

The model is a recipe.

Each train has a JSON template. Wheel positions, radii, frame length, lettering, and material colors feed the same Python generator.

Inside Blender, reusable functions make cylinders, boxes, rings, pipes, and rods. Repeated details share mesh geometry while remaining separately named, editable objects.

The drivers pairs below are [axle position, wheel radius] in model units. Three driving axles produce six driving wheels.

03

BUILD, RENDER, REFINE

Give the geometry a character.

Forest green and brass emphasize the separate boiler, domes, and running gear. The frame was shortened during review to keep the front proportions compact.

Blender renders let us inspect the silhouette, surfaces, and small details together. The source stays procedural, so a correction belongs in the generator or template and survives the next build.

04

KEEP THE PARTS SEPARATE

Understand it by taking it apart.

Nine assemblies organize each locomotive: body, chassis, wheels, valve gear, cab, fittings, tender, bogies, and couplers. The Blender files preserve all individual objects; each assembly also has its own GLB download.

The exploded view moves those groups away from their assembled positions. It reveals how the model is organized without changing the underlying geometry.

05

ADD TIME

Let the parts tell the story.

Our assembly replay starts with the complete train, separates the outer fittings, body, and undercarriage in stages, holds the exploded view, then brings it back together. Scrub the separation slider to examine any intermediate arrangement.

The browser animates group transforms on the exported GLBs. The reference thread also shows moving trains and a railway simulation; our motion here is an assembly demonstration, not a running-engine simulation.

MAKE IT YOURS

Every step has a source.

Edit a template, rebuild the geometry, then publish the viewer. The repository includes both Blender files, individual GLBs, render previews, generator code, and drawing prompts.

GitHub Actions checks all three branches and publishes the main site with separate dev and nightly paths. We are developing this walkthrough on main.
